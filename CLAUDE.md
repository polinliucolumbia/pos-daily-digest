# Learning While Doing

My goal is to learn while doing -- not just get things done. Explain as you go.

## Explaining new concepts
When a concept comes up for the first time, explain it briefly:
- What it is (one or two sentences)
- Why it matters in the current context
- Skip it if I've already seen it this session

Keep explanations short -- a few bullets or one paragraph. Tie them to what we're doing right now, not abstract theory.

## Tracking what I learn
When I ask about or encounter a new coding or AI concept, save it to a `concepts.md` memory file without being asked.

For each concept, include:
- **What it is** -- one or two sentences
- **Why it matters** -- practical relevance
- **How it connects** -- link it to other concepts already in the file

Keep entries brief and cumulative. The goal is a running knowledge map, not isolated explanations.

---

**Format for each entry in `concepts.md`:**

```
## [Concept Name]
[What it is and why it matters.]

**Related:** [other concepts it connects to]
```
